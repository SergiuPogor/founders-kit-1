# Product Submission Guide 🚀

Use this guide to submit your product or startup to the community directory in [Product.md](Product.md).

## How To Submit

1. Fork this repository (`pavanjoshi914/founders-kit`).
2. Open `Product.md`.
3. Copy the table row template below.
4. Add your row at the end of the `<tbody>` section under **Product Submissions**.
5. Ensure your website link is active and uses HTTPS.
6. Open a Pull Request titled: `Add [Product Name] to Product.md`.

## Submission Rules

- Only submit active products/services (no defunct links or placeholder landing pages).
- One product per pull request.
- Keep descriptions neutral, factual, and concise (under 120 characters).
- No affiliate or tracking parameters in URLs.

## Row Template

```html
<tr>
  <td>Your Product Name</td>
  <td>SaaS / AI / Developer Tools / Fintech / etc.</td>
  <td>Concise one-sentence description of what your product does.</td>
  <td>Founders / Engineers / Designers / etc.</td>
  <td>Free / Freemium / Paid</td>
  <td><a href="https://yourwebsite.com">Website</a></td>
</tr>
```
